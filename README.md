# 🔐 Java Login and Registration

## 📖 Sobre

Projeto Maven (`pom.xml`) de estudo de autenticação: cadastro e autenticação de usuários, com os arquivos de apoio do tutorial incluídos no repositório.

## 🚀 Como rodar

```bash
./mvnw spring-boot:run
```

## 🛠️ Tecnologias

Java • Maven

## 💡 O que aprendi

- Fluxo de registro + autenticação de usuários em Java
- Estrutura de um projeto Maven com wrapper (`mvnw`)
